IceWM is a window manager for the X Window System. The goal of IceWM is speed, simplicity, and not getting in the user’s way. It comes with a taskbar with pager, global and per-window keybindings and a dynamic menu system. Application windows can be managed by keyboard and mouse. Windows can be iconified to the taskbar, to the tray, to the desktop or be made hidden. They are controllable by a quick switch window (Alt+Tab) and in a window list. A handful of configurable focus models are menu-selectable. Setups with multiple monitors are supported by RandR and Xinerama. IceWM is very configurable, themeable and well documented. It includes an optional external background wallpaper manager with transparency support, a simple session manager and a system tray. IceWM is available on popular Linux distributions like Debian, Ubuntu, Arch, OpenSUSE, Gentoo, Slackware, CentOS, antiX, NixOS and on most *BSDs.

IceWM 是 X Window System 的一个窗口管理器。IceWM 的目标是速度、简洁，以及不干扰用户操作。它附带一个带分页器（pager）的任务栏、全局和每个窗口的快捷键绑定以及动态菜单系统。应用程序窗口可以通过键盘和鼠标进行管理。窗口可以最小化到任务栏、托盘、桌面，或者隐藏。它们可以通过快速窗口切换（Alt+Tab）和窗口列表进行控制。几种可配置的焦点模型可供菜单选择。多显示器设置受到 RandR 和 Xinerama 的支持。IceWM 可配置性强、支持主题定制，且文档完善。它包含一个可选的、支持透明效果的外部背景壁纸管理器、一个简单的会话管理器和一个系统托盘。IceWM is available 在流行的 Linux 发行版（如 Debian、Ubuntu、Arch、OpenSUSE、Gentoo、Slackware、CentOS、antiX、NixOS）以及大多数 *BSD 系统上。

Themes#

主题#

IceWM is themeable. The visual appearance of icewm can be changed by a theme, which is a collection of settings and small images. Over 450 themes can be downloaded from box-look.org. Extra is a collection of 91 highlights. See icewm -i list.

IceWM 是 themeable 的。其视觉外观可以通过 theme 进行更改，theme 是一组设置和小图像。超过 450 themes 可以从 box-look.org 下载。Extra 是 91 highlights 的集合。参见 icewm -i list。

Install the latest release as follows#

安装最新发行版如下#

$ wget https://github.com/ice-wm/icewm/releases/download/4.1.0/icewm-4.1.0.tar.lz
$ tar -x --lzip -vpf icewm-4.1.0.tar.lz
$ cd icewm-4.1.0
$ ./configure --prefix=/usr
$ make
$ sudo make install

Install from unreleased development source code#

从未发布的开发源代码进行安装#

Gettext must be installed.

必须安装 Gettext。

$ git clone https://github.com/bbidulock/icewm
$ cd icewm
$ ./autogen.sh
$ ./configure --prefix=/usr
$ make
$ sudo make install

If you have cmake, an alternative is:

如果你有 cmake，另一个方案是：

$ git clone https://github.com/bbidulock/icewm
$ cd icewm
$ ./rebuild.sh -r --prefix=/usr
$ cd build
$ sudo make install

Install package dependencies#

安装包依赖#

To install all package dependencies in one go use the following script.

要一次性安装所有包依赖，请使用以下脚本。

$ wget https://ice-wm.org/scripts/os-depends.sh
$ sudo bash -x ./os-depends.sh

Verify package dependencies by:

验证包依赖项：

$ pkg-config --modversion x11 xext xcomposite xcursor xdamage xfixes xres xrender xrandr xinerama xft fontconfig sm ice sndfile alsa ao gio-2.0 gio-unix-2.0 gdk-pixbuf-xlib-2.0 imlib2 librsvg-2.0 xpm libpng libjpeg
# or simpler:
$ ./rebuild.sh -d
