XNU Linux：在 Linux 上运行完整的 OS X GUI 用户空间

xnulinux XNU Linux 系统 Run macOS userspace on Linux by loading the macOS kernel into it. 在 Linux 上运行 macOS 用户空间，通过将 macOS 内核加载到其中。 xnulinux builds XNU, the open-source kernel of macOS, from Apple’s published sources and runs it as a loadable kernel module (xnu.ko) inside an unmodified arm64 Linux kernel. The hosted XNU drives the CPU and MMU directly, so macOS processes run natively next to Linux processes on the same CPUs, with no hypervisor between them.
